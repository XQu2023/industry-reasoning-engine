# Headline

结论先说：Anthropic 发布 Claude，把接入从封闭 alpha 伙伴，推到自家可控的聊天与 API 面，并拆出两条商业 SKU。

---

# Executive Summary

为什么值得关心？稀缺点在专有基座模型 API 入口，不在又一个聊天演示。2023 年 3 月 14 日，Anthropic 经聊天与 API 推出 Claude：Constitutional AI / HHH 框架，双 SKU（Claude 偏能力；Claude Instant 偏速度/成本），约 9k 上下文，T0 产品文案写明无联网、无 embeddings，伙伴嵌入已在 Poe、Notion AI、DuckAssist、辅导、法律审阅与转写中上线。超出先前封闭 alpha 的接入，经开发者控制台申请门控。若开发者经带信任定位的专有基座模型 API 交付助手功能，价值迁向该 API 所有者。**未披露**美元标价、利润率、付费转化或伙伴合同条款。抓取幅度，仍属 Unknown。

---

# What Changed?

变的是接入面与产品拆分，不是又一次封闭演示。2023 年 3 月 14 日（产品页事实取自 SRE-120 所用 2023 年 3 月 16 日存档），Anthropic 公开推出 Claude。

- Claude 经聊天与 API 可用；开发者控制台需申请接入。
- 双 SKU：Claude（更强）与 Claude Instant（更快/更便宜）。
- 安全/信任框架：Constitutional AI 与 Helpful, Honest, Harmless（HHH）；强调可引导性。
- T0 产品文案限制：约 9k 上下文、无联网、无 embeddings。
- 具名伙伴/用例：Poe、Notion AI、DuckAssist、Juni Learning、Robin AI、AssemblyAI，及相关 embeddings（见来源描述）。

---

# Why It Matters

问题只有一个：模型走出封闭 alpha 后，开发者怎么接。需要带清晰 SKU 与信任叙事的 API 与聊天面，不只私人伙伴集成。

Anthropic 的解法：受控商业表面。

1. **接入放宽** — 从仅伙伴 alpha，转向申请门控的聊天与 API。
2. **产品拆成双 SKU** — 能力对速度/成本。
3. **信任是卖点一部分** — Constitutional AI / HHH 作产品框架，并行经具名伙伴分发。

申请接入能否转成持续付费使用，仍属 Unknown。

# Where Value Is Moving

Simple value flow (five nodes):

```text
[封闭 alpha、仅伙伴的 Claude 接入]
        ↓
[申请门控的开发者控制台]
        ↓
[Claude / Claude Instant 双 SKU]
        ↓
[Anthropic 聊天 + API + Constitutional AI / HHH 框架]
        ↓
[相对 ChatGPT 评估的伙伴应用与开发者]
```

**Reading.** 若接入转成付费使用、伙伴继续嵌入 Claude，价值迁向 Anthropic 可控的商业聊天与 API 面（双 SKU）。Anthropic 为 Tier 1。美元价格与留存份额，仍属 Unknown。

# Reality Check

**Current thesis.** 开发者若经专有基座模型 API——双 SKU、Constitutional AI 式信任框架——交付助手功能，价值迁向 Anthropic 的 Claude 面。Anthropic 为 Tier 1；美元幅度仍属 Unknown。

**What would prove us wrong?**

- Anthropic 放弃商业 API。
- 盈余主要落在伙伴或买方。
- 开发者标准化到非 Claude API。
- 安全结果迫使产品下线。

**Next validation point.** 下一验证看：普遍开放注册并公布美元标价；伙伴扩出 T0 集合；上下文、工具或 embeddings 变化；对手 API 份额；伙伴结果披露。

---

# Bottom Line

方向清楚：Claude 上线卖的是门控聊天与 API 式基座模型接入，双 SKU 加信任产品，不是“又一个聊天机器人演示”。来源报告里，Anthropic 是 Tier 1 结构性受益方；伙伴是 Tier 2 分发。价格与留存盈余，仍属 Unknown。
