## Mission

Build a continuously learning strategic research system that turns **primary-source evidence** into Decision Briefs readers can trust — then validates those theses against reality and compounds the lessons into durable knowledge.

FORESIGHT exists to improve judgment under uncertainty:

- what changed
- why it matters
- where value is moving
- who may structurally benefit
- what remains **Unknown**

---

## North Star

**Understand how value moves. Think independently.**

Readers should leave each Brief with:

1. A clear structural question  
2. A reusable World Model  
3. Explicit conditions that would change today’s conclusion  
4. A path to continue thinking  

FORESIGHT is not a tip sheet, a blog, or a research dump.  
It is a **premium digital investment journal** backed by a disciplined reasoning engine.

## Product Definition

| Attribute | Definition |
| --- | --- |
| **Product unit** | Decision Brief (`DB-xxx`) |
| **Reading system** | FORESIGHT Journal (fixed layout) |
| **Evidence standard** | Primary (P0) sources found the thesis |
| **Reasoning standard** | Facts before inference; Unknown remains Unknown |
| **Validation standard** | Later dated evidence confirms, weakens, or falsifies |
| **Non-goals** | Stock tips, price targets, financial advice, hype narratives |

Core mental model:

```text
World Change → Customer Decision Change → Value Reallocation
```

Value **creation**, **migration**, and **capture** are kept distinct.

## Development Principles

1. **Truth before narrative** — The story follows evidence; evidence is never bent to fit the story.
2. **Evidence before opinion** — Observable facts are recorded before interpretation.
3. **Validation before prediction** — Structural clarity at freeze time is not predictive power.
4. **Trust before growth** — Reader trust outranks reach, frequency, and novelty.
5. **Compounding before speed** — One validated cycle beats many unvalidated outputs.
6. **P0 first** — Only primary, attributable sources may found a thesis.
7. **Unknown remains Unknown** — Unsupported certainty is a defect.
8. **Validate first. Upgrade second.** — Method changes require repeated defects, benchmark failures, or PVF failures.
9. **One Journal for all Briefs** — Layout is shared; articles are not individually redesigned.
10. **Documentation is the contract** — When code and docs diverge, restore alignment; do not silently invent product behavior.

## Success Metrics

FORESIGHT measures compounding assets and trust — not vanity volume alone.

| Metric | Meaning |
| --- | --- |
| **Decision Briefs** | Published briefs that meet the Brief / Journal standard and trace to research |
| **Engine quality (IRA)** | Reasoning fidelity on the IRB benchmark (max 100) |
| **PVF completed** | Validation cycles finished against named theses and horizons |
| **Track record** | Aggregate clarity of confirm / weaken / falsify outcomes |
| **Knowledge units** | Durable SKB lessons from completed cycles |
| **Trusted readers** | Readers who treat FORESIGHT as a long-term reference |
| **Returning readers** | Readers who return across briefs and cycles |
| **Journal QA pass rate** | Every shipped Brief passes Journal QA |
| **Writer score** | Editorial quality against Writer QA (see [WRITER_GUIDE.md](./WRITER_GUIDE.md)) |

Interpretation rules:

- Rising Briefs without validation or knowledge is **not** success.
- Rising traffic without trusted / returning readers is **not** success.
- Honest Unknowns and clean falsifications **improve** the track record.

Case-scale goals: see [ROADMAP.md](./ROADMAP.md) (100 → 300 → 1000).

## Governance

The system may evolve only when supported by evidence.

Changes are allowed only if at least one of the following is true:

- Multiple real cases expose the same methodological defect.
- Benchmark repeatedly identifies the same failure mode.
- Prediction Validation demonstrates a persistent forecasting failure.
- Brand or Journal QA shows a repeated reader-trust failure.

Otherwise:

**Maintain stability.**

Invalidated claims are marked superseded, not erased.
