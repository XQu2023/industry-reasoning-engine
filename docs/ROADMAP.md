## North Star

Scale the library of Decision Briefs **without** diluting trust.

```text
100 cases → 300 cases → 1000 cases
```

Each phase increases:

- coverage across industries  
- reusable World Models  
- validation track record  
- Journal consistency  

Each phase must **not** increase hallucination, advice language, or layout fragmentation.

---

## Phase 1 — 100 Cases

**Goal:** Prove the permanent FORESIGHT loop at small scale.

| Track | Target |
| --- | --- |
| Decision Briefs | **100** published (`DB-001` … `DB-100`) |
| Journal | All new Briefs ship on Journal layout |
| Engine | Frozen stages remain stable; IRA gates held |
| Writer | Writer QA + Writer Score on every Brief |
| Validation | PVF started on theses with due horizons |
| Brand | Circle + four-color system unchanged |

### Phase 1 exit criteria

- [ ] 100 Briefs meet Journal QA  
- [ ] No parallel article layouts for new Briefs  
- [ ] World Model present on every Brief  
- [ ] Change My Mind present on every Brief  
- [ ] Constitution + guides adopted as source of truth  
- [ ] Track record process (PVF) is operating, not theoretical  

### Phase 1 focus industries (illustrative)

AI infrastructure · Semiconductors · Cloud · Developer platforms · Industrial constraints (power, materials, manufacturing)

## Phase 2 — 300 Cases

**Goal:** Compound patterns and make validation visible.

| Track | Target |
| --- | --- |
| Decision Briefs | **300** published |
| Pattern Library | Recurring World Models catalogued across cases |
| PVF | Material share of due theses validated |
| SKB | Knowledge units extracted from completed cycles |
| Engine | Candidate Rules promoted only from repeated defects |
| Reader | Trusted / returning reader metrics reviewed quarterly |

### Phase 2 exit criteria

- [ ] 300 Briefs on one Journal system  
- [ ] Pattern Library has named recurring principles with falsifiers  
- [ ] Bug Database shows no open S0 hallucination bugs  
- [ ] Validation track record is publicly intelligible  
- [ ] Writer Score distribution stays healthy (see [WRITER_GUIDE.md](./WRITER_GUIDE.md#writer-score))  

---

## Phase 3 — 1000 Cases

**Goal:** Become a durable reference library for how value moves.

| Track | Target |
| --- | --- |
| Decision Briefs | **1000** published |
| Cross-domain transfer | World Models reused across many industries |
| Knowledge graph | Stable concept links between Briefs |
| Engine | Benchmark suite expanded with phase-appropriate locks |
| Trust | Long-horizon readers treat FORESIGHT as infrastructure |

### Phase 3 exit criteria

- [ ] 1000 Briefs without layout fragmentation  
- [ ] SKB is a working asset, not an empty folder contract  
- [ ] Confirm / weaken / falsify history is thick enough to teach  
- [ ] Documentation still matches product reality

## Future Milestones

Beyond case count, FORESIGHT may pursue the following **only** under constitution governance:

| Milestone | Intent |
| --- | --- |
| **Full Journal migration** | DB-001…N all on Journal (not only new Briefs) |
| **Bilingual parity** | EN/ZH completeness where a locale is offered |
| **Public track record surface** | Clear PVF outcomes beside Briefs |
| **Pattern atlas** | Browse World Models across the library |
| **Expanded IRB set** | More frozen benchmark cases as domains widen |
| **Contributor discipline** | External research still passes Engine / Writer / Journal QA |

Non-milestones:

- Becoming a stock-picking product  
- Redesigning Journal per article  
- Replacing primary evidence with narrative velocity
