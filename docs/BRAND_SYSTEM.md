## Mission

FORESIGHT helps readers see **where value flows** from **primary evidence**.

| Locale | Tagline |
| --- | --- |
| EN | Primary evidence. See where value flows. |
| ZH | 第一手证据，预见价值流向。 |

Footer lines (fixed):

- Understand how value moves.
- Think independently.

## Circle Meaning

The FORESIGHT mark is a **circle with the letter F**.

The circle stands for:

1. **Focus** — one structural question at a time  
2. **Cycle** — research → brief → validation → knowledge → next brief  
3. **Horizon** — looking forward without inventing certainty  

It is not a decorative badge. It is the only icon system FORESIGHT uses in Journal.

---

## Circle Usage

| Context | Usage |
| --- | --- |
| Journal Hero | Circle + `FORESIGHT` wordmark, links home |
| Journal Footer | Circle + wordmark on dark ground |
| Homepage / chrome | Wordmark FORESIGHT; Chinese subtitle 预见 where appropriate |
| Diagrams | Do **not** use the circle as a node icon |
| Third-party icons | Forbidden in Journal |

## Logo Rules

| Rule | Detail |
| --- | --- |
| Wordmark | `FORESIGHT` in Latin capitals |
| Subtitle | `预见` (Chinese), optional beside / under mark on homepage |
| Monogram | Circular F only |
| Clear space | Do not crowd the mark with chips, stickers, or badges |
| Alteration | No gradients on the mark, no shadows, no extra icons |
| Color | FORESIGHT Green on light; inverted (white circle) on black footer |

Do not introduce another logo family for Briefs.

## Typography

Journal allows five sizes only — see [JOURNAL_GUIDE.md](./JOURNAL_GUIDE.md#typography).

Brand type roles:

| Role | Family |
| --- | --- |
| Display / quote | Fraunces |
| Reading body | Source Serif 4 |
| UI / meta | IBM Plex Sans |
| Simplified Chinese | Noto Sans SC |

Avoid default UI stacks (Inter, Roboto, Arial, system) for FORESIGHT surfaces.

## Color Tokens

Journal and brand chrome use **only** these four colors:

| Token | Hex | Role |
| --- | --- | --- |
| **FORESIGHT Green** | `#1a453a` | Brand, quotes, Key Insight band, links |
| **Black** | `#12161a` | Primary text, footer ground |
| **White** | `#ffffff` | Page ground, Key Insight text on green |
| **Warm Gray** | `#ebe6df` | Atmosphere, Diagram band, World Model card |

No additional accent colors in Journal.  
No purple glow systems. No multi-layer neon.

## Motion

Motion exists to create presence and hierarchy — not noise.

| Guidance | Practice |
| --- | --- |
| Intentional | Prefer 2–3 purposeful motions on visually led surfaces |
| Restraint | No endless particle effects or bouncing badges |
| Reading | Journal prioritizes stillness; motion must not interrupt reading |
| Transitions | Soft opacity / position only when they clarify section change |

If motion competes with the sentence, remove the motion.

## Diagram Language

Diagrams are part of the brand.

| Element | Rule |
| --- | --- |
| Node | Rectangle / quiet box; caption typography |
| Arrow | Simple → (or vertical on small screens) |
| Line | Minimal; structural |
| Color | Black text, green arrows, white/warm-gray surfaces |
| Content | Bottleneck chains, not org charts |

Forbidden: illustration packs, emoji, 3D renders, dense multi-series charts as a substitute for structure.

## Editorial Language

Preferred vocabulary:

| Prefer | Avoid |
| --- | --- |
| Primary evidence / 第一手来源 | “Sources say” without attribution |
| Value flow / 价值流向 | Vague “disruption” |
| Bottleneck / constraint | “Winner takes all” as default |
| Unknown / 待确认 | Fake certainty |
| Continuously validate / 持续验证 | One-shot prediction theater |
| Knowledge compounds / 知识沉淀 | Disposable hot takes |

Product name in public: **Decision Brief**.  
Reading system name: **Journal**.

## Brand Voice

| Attribute | Expression |
| --- | --- |
| Calm | Short sentences; no exclamation culture |
| Independent | No issuer marketing language |
| Precise | Concrete nouns; dated evidence when claims need it |
| Humble | “I don’t know” is on-brand |
| Structural | Teach models, not tips |

Voice is shared by Homepage, Writer, and Journal.
